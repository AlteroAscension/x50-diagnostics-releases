# 0.1.0 preview

Первая версия X50 Диагностики для Android8+ без root.

- Подключение ESP32 / CAN485 по USB и Bluetooth Classic.
- Чтение приборки и профиля аккумулятора, исходные копии и контроль записи через ESP.
- ELM327 по Bluetooth Classic / USB: чтение. Запись через ELM пока не включена.
- Отдельный экран первой установки и обновления ESP32 по USB телефона.
- В APK включён полный образ ESP32 / CAN4850.2.0 для платы8МБ, CAN TX27/RX26.
- Журнал и копии хранятся локально; выгрузка через системное сохранение файла.
- ESP32-C3 и BLE будут добавлены позднее. Образ ESP32 на C3 не подходит.

Проверены сборки, подпись APK, тесты диагностического ядра и протоколов,
имитатор ROM-загрузчика и экраны на отдельном Android30-эмуляторе.
**Физический телефон, Bluetooth/USB-адаптеры и прошивка платы из Android ещё не проверены.**
Это предварительная версия для начала испытаний. Старый HTML остаётся отдельно.

Для прошивки отключите CAN. Выбирайте только ESP32 с8МБ flash и соответствующей
обвязкой. Приложение проверяет тип чипа и объём flash до стирания, затем сравнивает
контрольную сумму записанного образа. Если автозагрузка не сработала — BOOT+RESET.

Обновление из приложения сейчас устанавливает образ, включённый в APK.
Автоматическая загрузка новых прошивок из интернета пока не добавлена.
