# 0.2.1 preview — VIN и обновления приложения

Android0.2.1, встроенная прошивка ESP32 / WeAct CAN4850.3.1.

- ELM327 доступен только по Bluetooth. Удалены пункты с обещаниями будущей поддержки C3.
- После подключения автоматически читается VIN двигателя: OBD09/02 на7E0/7E8, с резервным запросом22F190. Старые прошивки ESP сразу используют22F190. VIN выводится сверху; неудачное чтение VIN сохраняет соединение с адаптером.
- В журнале есть «Очистить журнал» с подтверждением. Очищаются также предыдущий журнал и счётчик ошибок; резервные копии блоков сохраняются.
- Последний раздел переименован в «Прошивка и обновление». В нём показана версия приложения и доступны проверка GitHub-релиза, загрузка и установка обновления.
- Перед установкой APK проверяются размер, SHA256, пакет, версия и совпадение подписи. Android запрашивает разрешение на установку из приложения и подтверждение установки. Установка прошивки ESP остаётся отдельной операцией по USB.

Сборки, производственные Java/C++ тесты, интерфейс и автоматическое чтение VIN через тестовый транспорт проверены. Ошибка VIN не сбрасывает рабочее соединение. Тесты очистки подтверждают сохранность копий. Пробы на реальном автомобиле и установка новой прошивки на плату при подготовке релиза не выполнялись.
