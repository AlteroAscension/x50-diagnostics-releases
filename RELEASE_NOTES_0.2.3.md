# 0.2.3 preview — пробная запись через ELM

- Для ELM добавлена кнопка «Пробная запись через ELM» в разделах приборки и АКБ.
- Перед попыткой нужны чтение блока, сохранённая исходная копия, изменение значения и подтверждение. Перед записью повторно проверяются идентификаторы и исходная конфигурация.
- Приборка: F101,16байт, G5 /6600003138; получение доступа и многочастная передача с контролем Flow Control, STmin и интервалов. G6, F110 и идентификаторы остаются без записи.
- АКБ: короткая команда записи, сброс диагностической сессии, повторный доступ и контрольное чтение.
- Если на полностью переданный запрос нет ответа, выполняется контрольное чтение без повторной записи. Успех возможен только при совпадении результата; отсутствие исходного подтверждения сохраняется в журнале отдельно.
- Журнал показывает этап, ответы ELM, Flow Control, интервалы кадров и причину ошибки. Автоматических повторов записи или ключа нет.

На старом веб-логе доступ и первый Flow Control проходили, но завершающего ответа не было. В Android сокращено промежуточное ожидание ELM и добавлена проверка результата при потерянном ответе. Это гипотеза для проверки, а не доказательство, что телефон устранит проблему.

Прошли сборка, производственные Java/C++ тесты с моделями адаптера/ECU и проверки интерфейса на эмуляторе. Запись через реальный ELM этой версией пока не подтверждена. Прошивка ESP32 остаётся0.3.1; для ELM обновлять ESP не нужно.
APK0.2.3 установлен обновлением на телефон Android13 без рута; при установке запросы в автомобиль не отправлялись.
