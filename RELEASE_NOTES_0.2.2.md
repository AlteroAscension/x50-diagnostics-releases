# 0.2.2 preview — завершение установки обновления

Включает изменения0.2.1: ELM только Bluetooth, автоматическое чтение VIN, очистку журнала с сохранением копий и раздел «Прошивка и обновление» с загрузкой APK из GitHub Releases. Прошивка ESP32 остаётся0.3.1.

Исправлено восстановление загруженного обновления после перезапуска приложения, в том числе при изменении разрешения Android на установку из этого источника. Перед восстановлением повторно проверяются размер, SHA256, пакет, версия и подпись APK. После выдачи разрешения установка передаётся системному установщику Android.

Прошли сборка, тесты производственного Java/C++ кода, проверки редактора, очистки журнала и чтения VIN на выделенном эмуляторе с тестовыми транспортами. Новые CAN-пробы на автомобиле и прошивка физической платы не выполнялись.

На эмуляторе пройден полный сценарий: приложение нашло релиз на GitHub, загрузило настоящий APK0.2.2, восстановило его после принудительного перезапуска, прошло разрешение Android и установило обновление системным установщиком. Проверки отклоняют изменённый файл, неверный хеш и несовпавшую версию.
