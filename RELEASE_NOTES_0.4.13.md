# X50 Диагностика 0.4.13 preview

## ID датчиков TPMS для SX11 G5

В обслуживании BCM добавлена отдельная операция чтения и записи ID датчиков.
Можно выбрать одно или несколько колёс, дважды ввести новые ID либо вручную
повторить запись прежнего ID. Значения остальных колёс берутся из свежего
снимка BCM; блок получает полный набор из 16 байтов.

Перед записью приложение проверяет VIN и исходные данные, сохраняет журнал и
запрашивает подтверждение. После единственной записи выполняются полное
контрольное чтение и отдельно подтверждаемый самотест. При неизвестном исходе
повтор блокируется. Новая попытка доступна после свежего чтения и явной ручной
сверки предыдущей; автоматического повтора нет. Журнал можно сохранить.

Операция поддерживает ELM в режиме записи, CAN485 с `launch_can_v1` и ESP32-C5.
Профиль — SX11 G5, BCM `7E2/7EA` на OBD 6/14. Переключение на контакты 3/11,
X50+ G6 и X70 для этой операции не реализованы. Порядок колёс требует проверки
на автомобиле.

## Установка и проверка

Установите APK 0.4.13 поверх предыдущей версии без удаления приложения и данных.
Подпись приложения сохранена. Встроенные прошивки прежние: CAN485 0.8.10 и
ESP32-C5 0.1.0; для этой версии не требуется их повторная прошивка, если нужная
версия уже установлена.

Проверены хостовые модели ELM и ESP, production-код CAN485 Launch CAN и C5 raw
CAN с синтетическим BCM, а также экран и хранение попытки на Android-эмуляторе.
Процедура ещё не проверена на физическом адаптере и автомобиле. Подтверждение
запуска самотеста не доказывает приём данных датчиков или сохранение ID после
отключения питания; `hardware_verified=false`.

Публичные файлы: APK, два раздельных factory-образа, их manifest, manifest
приложения и SHA256SUMS. Исходники и частные журналы не публикуются.
