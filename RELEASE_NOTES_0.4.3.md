# Diagnostics0.4.3 preview / WeAct CAN4850.8.3

Исправлен расчёт памяти для запуска записи CAN на microSD после сообщения
`257 / mount` в0.8.2. Ошибка означает нехватку RAM; само наличие карты её
не исключает. Старый расчёт выделял CAN-очередь без достаточного запаса
для крупного единого блока файловой системы FAT/VFS.

- Теперь оставляется память для FAT,10KiB стека записи, драйвера SD и Bluetooth.
  Размер очереди128–1024 выбирается по общей и непрерывной свободной памяти.
  При меньшем остатке RAM очередь будет меньше, чем в0.8.2.
- Приложение различает этапы `spi_bus`, `mount`, `mkdir`, `scan`, показывает RAM
  перед соответствующим этапом и относит257/mount к нехватке памяти.
- Файлы, CAN-дата начала,30секунд тишины, новый файл при пробуждении,
  самостоятельная запись без телефона и режим listen-only сохранены.

Сборки, полный host-набор CAN/диагностики/SD/часов, модель нехватки/фрагментации
RAM и оба интерфейса Android на эмуляторе прошли проверку. Точный образ из APK
проверен производственным USB ROM-установщиком на host-модели, включая MD5/readback.
Работа с настоящей картой, устранение сбоя на физической плате и ночной захват
после изменения ещё не проверены. Это preview, `hardware_verified=false`.
Меньшая очередь уменьшает запас на задержки SD; отсутствие потерь нужно проверить
на используемой карте и шине.

Установите APK поверх предыдущего, без удаления приложения/истории. Затем отдельно
выберите установку встроенной **прошивки0.8.3** через USB OTG. Обновление APK само
не обновляет плату. Перед прошивкой отключите CAN и извлеките microSD. Цель образа:
обычный ESP32 WeAct CAN485 с8MiB flash, полный factory-образ для адреса0x0.
ESP32-C3 и произвольные4MiB-платы не поддерживаются этим образом.

Верните FAT32-карту при отключённом питании и снова выберите режим записи.
Перед ночным захватом проверьте текущий файл, рост frames/synced, отсутствие
ошибок/потерь при подключении и отключении Bluetooth. При повторном отказе
сохраните код/этап, вместимость очереди и все строки RAM. Форматировать карту
из-за одного257/mount не требуется; плата карту не форматирует и файлы не удаляет.
