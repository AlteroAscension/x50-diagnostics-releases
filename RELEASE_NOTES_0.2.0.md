# 0.2.0 preview — редактор конфигурации и журнал

Android 0.2.0, встроенная прошивка ESP32 / WeAct CAN485 0.3.0.

- Убран большой заголовок. Подсказки подключения соответствуют выбранному USB или Bluetooth.
- Запоминаются последний успешно подключённый адаптер и режим отдельно для каждого типа устройства. Подключение запускается кнопкой; есть выбор другого устройства.
- Диагностика разделена на приборную панель и аккумулятор. Чтение и запись доступны внутри раздела.
- F101: показ всех 16 байт, редактирование HEX и отдельных битов, подсветка отличий, подтверждение со списком изменений.
- АКБ: редактирование байта HEX/битами и выбор известного профиля. Неизвестный код не получает выдуманного описания.
- F110: полное чтение, отображение и резервная копия. Запись не добавлена: это отдельная конфигурация сетевых узлов, назначение отдельных битов пока не установлено.
- Идентификационные данные показаны полностью и доступны только для чтения.
- Журнал открывается нижней панелью с любого экрана, в том числе во время операции: понятные сообщения, фильтр ошибок, подробности и экспорт.

Для записи произвольных байтов требуется обновить ESP32 до 0.3.0 через раздел «Прошивка», отключив CAN перед прошивкой. Старые версии прошивки остаются доступны для чтения. Перед записью сохраняется исходная копия; прошивка проверяет идентичность блока, неизменность исходных данных и полное контрольное чтение. Автоматических повторов записи нет.

Проверены сборки, подпись APK, тесты производственного Java/C++ кода и интерфейс на выделенном эмуляторе. APK установлен обновлением на телефон Android13 без рута; проверены разделы, журнал, подсказки и сохранение режима подключения. Проверки редактора используют отдельное тестовое приложение и тестовый блок, без подключения к адаптеру; оно не входит в релиз. Новая запись произвольных значений в автомобиль не проверялась. Поддержка C3/BLE и запись через ELM остаются следующими этапами.
