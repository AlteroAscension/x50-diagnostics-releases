# 0.1.1 preview — ускорение USB-прошивки

- Быстрый режим:921600 бит/с вместо115200. Соединение и проверки платы начинаются
  на115200, высокая скорость проверяется до стирания.
- Сжатая передача: образ1,188,096байт отправляется как728,117байт.
- Сокращено число отдельных USB-передач CH343 и обновлений индикатора прогресса.
- Есть режим совместимости115200 бит/с, также со сжатием.
- Исправлена ошибка команды4 после успешной проверки образа: завершение теперь
  выполняется сбросом платы без лишней команды ROM.
- Этапы прошивки сохраняются в журнале для проверки реального времени и ошибок.

Образ ESP32 остаётся0.2.0, его содержимое не менялось. Это обновление Android APK.
Проверены сборка/подпись и тесты ROM-протокола с распаковкой переданных данных,
контрольной суммой и блокировкой стирания при неудачном переключении скорости.
Теоретический минимум передачи снизился со103до8секунд; это не замер полного
времени прошивки на телефоне. Проверка новой скорости на физической плате ещё нужна.

Поддержка C3/BLE и запись через ELM остаются следующими этапами.
