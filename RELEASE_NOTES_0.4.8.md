# Diagnostics 0.4.8 preview / WeAct CAN485 0.8.8

Встроенная прошивка0.8.8 для обычного ESP32 WeAct CAN485 с8MiB flash.
Обновить нужно приложение и отдельно плату. Установка APK поверх прежнего
сохраняет историю приложения; удаление и очистка данных не требуются.

## ГУ при автозапуске

В настройках платы рядом с записью на microSD добавлен пункт
**«Активировать ГУ при автозапуске»**. По умолчанию выключен, сохраняется в плате.
Работает автономно без телефона только вместе с записью SD.

- До **трёх попыток за запуск**, включая первую, с паузой **3секунды** после
  известного результата предыдущего CAN TX. ACK на шине не подтверждает
  загрузку Android и сам по себе не отменяет следующий запрос.
- Каждая попытка берёт новый штатный0x284 и меняет только исследованное поле.
  Повторно проверяются RUN, выключенный ACC, закрытая дверь/gate и готовность SD.
- Изменение поля0x2A8, условий запуска, настройки или ошибка SD/постановки TX
  отменяют оставшиеся попытки. При неизвестном исходе CAN TX повторов нет
  до перезапуска платы; поздний ACK серию не возобновляет.
- В статусе: число попыток за этот запуск N/3, пауза, результат и причина остановки.
  В SD-логе: условия, свежий шаблон, запрос TX, результат CAN, наблюдения0x2A8,
  ожидание/готовность/остановка серии. Формат v2 и запись32байта сохранены.
- CAN сразу открывается в **normal с ACK**. Паузы неблокирующие, без
  переоткрытия CAN/SD. Произвольная диагностика при записи остаётся запрещена.

RUN при выключенном ACC — кандидат автозапуска, не универсальный определитель
сигнализации.0x2A8 — кандидат активности Android/ECP, **не подтверждение загрузки**.
Работа Android и подсветки на настоящем ГУ этой сборкой ещё не проверена.

## Запись CAN на SD

Сохранены автономная запись, имена по CAN-дате начала, новая запись после30секунд
тишины и статус файла/ошибок/потерь. Включено изменение SD writer из0.8.6:
пакетный разбор очереди, отложенная обслуживающая работа под нагрузкой,
checkpoint1секунда с отсрочкой запроса до5секунд, штатный SPI максимум20МГц
вместо прежнего ограничения4МГц, новые показатели задержек SD.

В модели900кадров очереди плюс16служебных событий и задержке SD600мс потерь нет.
Это не измерение карты: устранение прежних потерь кадров и полноценный ночной
захват на настоящей плате новым образом ещё требуют проверки. При внезапном
обесточивании часть данных после последней синхронизации может не сохраниться.
Резервы памяти, очередь RX, стек писателя и тракт SD при добавлении повторов
ГУ не урезаны. Плата карту не форматирует и старые файлы не удаляет.

## Другие изменения после публичной0.4.4

Включены функции0.4.5/0.8.5 для двигателя через ESP и ELM: чтение версий и
экспериментальное чтение явно заданного диапазона памяти с сохранением
подтверждённого префикса/частичного результата и контрольной суммы.
Автоматической карты адресов или подтверждённого полного дампа нет;
стирание/запись прошивки двигателя не добавлены.

## Проверка и установка

Прошли сборки, полный host-набор диагностики ESP/ELM, CAN/SD/часов/памяти,
новые проверки трёх попыток и отмен, оба интерфейса Android на эмуляторе,
ROM-модель точного фабричного образа внутри APK и SHA256/MD5.
Это не проверка настоящего телефона, радио, SD, автомобиля или загрузки ГУ;
`hardware_verified=false`.

1. Установить APK поверх прежнего приложения.
2. Для обновления платы отключить CAN и извлечь microSD. Через встроенный
   USB OTG-установщик прошить0.8.8. Образ factory предназначен для адреса0x0,
   ESP32/8MiB; он не подходит ESP32-C3 и произвольным4MiB-платам.
3. При выключенном питании вернуть FAT32 microSD. Настройки платы после
   factory-обновления может потребоваться выбрать заново.
4. Сначала с выключенной функцией ГУ проверить рост frames/synced, имя файла,
   отсутствие ошибок/потерь и разделение файлов после тишины.
5. Для пробы включить функцию ГУ **до** автозапуска, оставить плату подключённой
   до сна машины. Отдельно отметить загрузку Android и включение подсветки.
6. После опыта выключить функцию, завершить запись, дождаться закрытия SD,
   сохранить.x50can и финальные счётчики. CAN ACK и активность0x2A8 не подменяют
   визуальную проверку ГУ.

Для отключения проб ГУ достаточно выключить пункт и сохранить настройку.
Предыдущий релиз0.4.4 остаётся доступен в истории релизов; его встроенная
прошивка0.8.4 возвращает прежний режим listen-only. Android может запрещать
понижение versionCode; ради отката платы не нужно удалять историю приложения.
